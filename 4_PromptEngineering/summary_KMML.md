# 1. 개요
- 목적: 기존 한국어 벤치마크들이 영어에서 번역된 문항들로 이루어져 있어 한국어 고유의 표현, 문화·법·지역 지식 등을 제대로 평가하지 못한다는 문제를 해결하기 위해, 원문 한국어 시험지에서 수집한 ‘전문가 수준(expert-level)’ 다과목(45개 과목) 객관식 벤치마크 KMMLU를 제안.  
- 핵심 아이디어: 번역을 거치지 않은 원문 문제는 한국어 특유의 어휘·구문·담화 관습과 한국 고유 지식(예: 한국사, 국내법 등)을 온전히 반영하므로 한국어 능력·지식 평가에 더 적합함.

# 2. 데이터셋 구성 및 공개
- 전체 규모와 분할
  - 테스트셋(공개 평가용): 35,030 문항 (객관식)  
  - 전체 수집 코퍼스: 약 243,777 문항(크롤링·전처리 후)  
  - 공개된 학습/검증/테스트 분할 예시: train 약 208,522, dev few-shot: 과목별 5개 exemplars, validation: 225, test: 35,030 (정확한 파일·분할은 Hugging Face 레포 참조)
- 과목·메타데이터
  - 45개 과목(인문·사회·자연·응용·전문 영역 포함), 각 문항에 과목 레이블·난이도·출처·키워드 등 메타 제공.
  - KMMLU-KOR: 한국 특화 문항 하위집합(예: 문화·지역·법 관련, 1,305개) 존재.  
  - KMMLU-HARD: 여러 강력한 모델이 실패한 난이도 높은 문항 하위집합(약 4,104개).
- 수집·품질관리
  - 출처: 공인·공개된 국내 시험(면허시험, PSAT, CSAT 등)에서 자동 크롤링 → 중복·잡음 필터링(정규식·불용어·모델 분류기 등) → 포맷 표준화(선택지 4개 등) → 테스트셋은 수동 검토.
  - 인간 응답 메타: 약 90%의 시험에서 수집 가능한 인적 성능 통계 존재(평균 인간 정확도 예: 62.6%), 일부 시험의 합격 기준(≥80%)을 근거로 난이도 해석 가능.
  - 저작권·윤리 검토: 공개 사전검토(6개월 커뮤니티 피드백, 741건 수정), 저작권 문제로 교체된 항목(147건) 보고. 구체적 라이선스·사용제약은 공개 레포지토리에 명시.
- 공개·재현성 인프라
  - 데이터셋과 평가 코드는 Hugging Face Hub에 공개(HAERAE-HUB/KMMLU)되고 EleutherAI의 lm-evaluation-harness에 통합되어 재현 가능한 평가지원. 프롬프트 템플릿·채점 스크립트·토크나이저/추론 설정 등 포함.

# 3. 평가 프로토콜 및 실험설계
- 평가 방식
  - MMLU 스타일의 객관식 정확도(accuracy)를 주 지표로 사용. 주로 5-shot 설정을 사용(Direct와 Chain-of-Thought(CoT) 변형을 병행).
  - Direct: 모델이 바로 선택지를 예측.  
  - CoT: 5-shot CoT exemplars(과목별 5개, 총 225개 CoT) 제공 → 자유형 추론 생성 후 정규식 기반으로 답 추출. CoT exemplars는 LLM 보조 생성 + 인간 검수로 작성됨.
- 오염(Contamination) 체크
  - 패러프레이징·퍼플렉서티·n-그램 오버랩 기반 검사(예: GPT-4 기반 패러프레이즈로 비교) → 대체로 데이터 누설 가능성 낮음 보고.
- 실험 자원·세팅
  - 모델군: 총 27개(또는 확장 평가에서 31개) 모델 실험. 범주: 다중언어 프리트레인 모델, 다국어 챗 모델, 한국어 프리트레인/연속학습 모델, 국내 상용 모델(프로프라이어터리).
  - 프롬프트·토크나이저·샘플링 설정 등은 레포지토리의 실행 스크립트로 재현 가능.

# 4. 주요 실험 결과
- 전반적 성능 경향
  - 최고 공개 모델: 약 50.5% 정확도(해당 공개 모델은 주로 영어·중국어 트레이닝 중심).  
  - 최고 상용 모델: GPT-4 약 59.95%로 보고된 최고점에 근접(다양한 표기에서 59–60% 근방).  
  - HyperCLOVA X(한국 특화 모델): 전 범주에서 60%를 넘지 못했으나 한국 지역·역사 등 로컬 분야에서 일부 강점(예: 한국사에서 44% vs GPT-4 약 35%)을 보임.
  - 한국어 특화 공개 모델(예: POLYGLOT-KO 등)은 기대보다 낮은 성능(대체로 25–40% 범위 혹은 일부 경우 ~29%)을 보임.
- 과목·현상별 차이
  - 과목별 편차 큼: 일부 과목(컴퓨터 과학·마케팅 등)에서는 상위 모델이 높은 성능을 보이나, 수학·기초 STEM 일부는 낮은 성능(≈26–31%)을 보임.
  - 부정(negation)·담론·문화지식 관련 문항에서 성능 차이가 뚜렷함(예: HUMSS 과목에 부정문이 많아 모델별 효과 상이).
- CoT 및 프롬프트 영향
  - CoT는 일부 한국어 모델(특히 HyperCLOVA X의 HARD subset)에 유의미한 개선을 주었으나, 다른 모델들에서는 성능 저하 또는 일관되지 않은 효과를 보임 → 모델별 추론·설명 생성 특성 차이 존재.
- 해석
  - 전반적 성능 격차는 프리트레이닝 데이터의 언어·문화 편중, 한국어 대규모 코퍼스 부족, 지속적 한국어 학습(continual pretraining) 미비, 어휘 확장·토크나이저 변경시의 언더트레이닝 문제 등에서 기인하는 것으로 분석.

# 5. 한계 및 윤리적 고려
- 데이터·평가의 한계
  - 저작권으로 인해 일부 도메인(국어, 의료, 금융 등)에서 문항 제거로 커버리지 편향 발생.  
  - 인간 응답 집단의 이질성(시험 응시자 풀 다양성) 때문에 인간–모델 직접 비교가 어렵고, 공개 인간 성능 지표 해석에 주의 필요.  
  - CoT exemplars의 일부는 LLM 보조 생성 후 인간 수정으로 제작되어 ‘순수 인간 생성’ 설명과 차이가 있을 수 있음.  
  - 잔존 가능한 누출·암기(benchmark contamination) 위험을 완전히 배제하기 어려움(다만 사전 검사 결과 위험도 낮음).
- 윤리·법적 고려
  - 출처 시험 자료의 저작권·프라이버시 문제 해결을 위해 일부 항목 제거/대체 및 공개 리뷰 절차 수행. 공개 사용시 라이선스·저작권 조건 준수 필요.
  - 교육·문화 자료 기반인 만큼 원자료에 내재된 사회적 편향·민감 콘텐츠가 포함될 수 있으므로 편향 분석·감수 권장.

# 6. 기여 및 향후 권장사항
- 주요 기여
  - 한국어 원문(비번역) 기반 대규모·전문가 수준의 다과목 객관식 벤치마크 제공(35,030 테스트 문항, 총 수십만 규모의 코퍼스 및 메타데이터).  
  - Hugging Face 공개 배포와 EleutherAI LM-Eval-Harness 통합을 통해 재현 가능한 평가 파이프라인 제공.  
  - 27개 모델에 대한 광범위한 실험으로 한국어·문화 중심 능력의 현 상태와 격차를 정량적으로 제시.
- 권장 후속 연구
  - 한국어 중심의 프리트레이닝·대규모 코퍼스 구축 및 타겟 파인튜닝(continual pretraining) 연구.  
  - 도메인별(의료·법·금융 등) 데이터 보강 및 전문가 해설(신뢰 가능한 CoT) 수집.  
  - 편향·민감도 감사, 저작권·프라이버시 정밀 검토, 통계적 유의성 분석(과목·난이도별) 강화.  
  - 생성형·지시추종(instruction-following) 평가지표 확장(객관식 외 자유생성 평가) 및 다중방언·문화 확장.

# 7. 결론
KMMLU는 한국어 고유의 언어·문화적 특성과 전문가 수준 문제를 반영한 실용적·재현 가능한 벤치마크로서, 현재 LLM들이 한국어·한국 지식 영역에서 여전히 큰 개선 여지가 있음을 실험적으로 보여준다. 공개 데이터·평가 툴을 통해 한국어 중심 모델 개선(프리트레이닝, 파인튜닝, 데이터 보강 등)을 촉진하고, 윤리적·법적 고려를 병행한 후속 연구가 필요하다.

(데이터·코드·라이선스 및 구체적 파일 포맷·프롬프트 템플릿 등은 Hugging Face 레포와 EleutherAI lm-eval-harness 통합 레포를 참조하십시오.)
